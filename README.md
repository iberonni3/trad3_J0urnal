# Project Name

A modern web application built with React, TypeScript, Vite, Tailwind CSS, and shadcn-ui.

## 🚀 Overview

This project is a fast, responsive frontend application using a modern React stack. It is optimized for developer experience, performance, and clean UI components.

## 🛠 Tech Stack

- **Vite** – Fast build tool and dev server  
- **React** – UI library  
- **TypeScript** – Type-safe JavaScript  
- **Tailwind CSS** – Utility-first CSS framework  
- **shadcn-ui** – Reusable UI components
